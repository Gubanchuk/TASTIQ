## Реализация и ход проверки

Владелец прямо поручил «убери все ограничения и чтобы нормально работало». В обычном AI-подборе сняты квоты30/час и500/день и неиспользуемая проверка подписки. Проверка наличия серверного ключа и явный AI_ACCESS=off сохранены для бесплатных offline fixtures. No-op aiSpend оставлен совместимым с существующими контроллерами; счётчики и их накопление удалены.

Удалён внутренний45-секундный deadline транспорта OpenAI. Обычный запрос ожидает ответ без собственного AbortSignal timeout; явный timeoutMs остаётся только для вызывающего кода, который сам его передал. Автоматических повторных генераций нет. Browser conversation-client ранее не прерывал fetch таймером. В Vercel Build Output API maxDuration увеличен с60 до300 секунд: актуальный resourceConfig.fluid=true, Hobby допускает300с. Это лимит хостинга, не отменяемый кодом сайта. [Vercel duration](https://vercel.com/docs/functions/configuring-functions/duration).

Валидация/источники фактов, пожелания пользователя, ограничения каталога/возраста/платформы и конечный output budget модели не изменены. Опциональный QA-сеанс по-прежнему изолирован от обычных stores/journal; его технические caps не применяются к обычным HTTP.
