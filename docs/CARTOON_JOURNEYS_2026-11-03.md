# Мультфильмные сценарии — 03.11.2026

Владелец одобрил следующий этап после копирования подбора: новые сохраняемые запросы, чтобы отделить понимание желания, доступность в каталоге и выбор модели. Исходный запрос прежнего тестировщика потерян; причину его промаха этот этап не устанавливает.

План и первичные материалы: [plan.json](../research-vault/cartoon-journeys-2026-11-03/plan.json), [машинная сверка](../research-vault/cartoon-journeys-2026-11-03/verification.json). Один исходный plan на сценарий, без автоматических платных повторов. После найденных ошибок тот же ответ воспроизведён бесплатно. Реальные ответы и промежуточные ошибки сохранены отдельно в live-round-1…5; они не переписаны удачным итогом.

## Что исправлено

1. Модель записала «Хочу анимационный сериал» как факт format.animation, но оставила context.format пустым. Ограничение 30 минут случайно удерживало выдачу в сериалах; после снятия времени формат терялся бы. Проверка теперь восстанавливает независимо подтверждённый формат из точной активной цитаты запроса. История, отрицание, условие, выбор «фильм или сериал» и реплика героя из синопсиса формат не задают. Снятие времени сохраняет формат; удаление самого формата снимает обе привязки, undo возвращает их.
2. Фраза «Сегодня на просмотр есть 90 минут» отклонялась грамматикой времени, рассчитанной прежде всего на игру. Добавлено одно слово назначения «просмотр»; ограничения на неопределённость, прошлое, отрицание, диапазон, условие и снятый источник сохраняются.
3. Реальное «Показать ещё» выбрало «Котов-аристократов» с собственной оговоркой модели, что фильм не отвечает строгому запрету страшных сцен. В adaptive media устранено требование ровно четырёх рекомендаций и ложное утверждение, будто каталог уже проверил все смысловые запреты. Модель должна пропускать известный конфликт, даже если останется меньше вариантов; автоматического дополнения по порядку движка нет. Legacy и game сохраняют прежний режим.
4. Повторный опыт с новым правилом предложил один тайтл, который каталог не подтвердил. Он не показан, прежние карточки сохранены. Вместо технического «нейросеть выбрала не из списка» теперь объясняется проверка каталога/условий, без кнопки платного повтора. Отдельно обработан намеренно пустой ответ модели.
