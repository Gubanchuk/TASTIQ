# Ночная доработка игрового подбора — 01.11.2026

Владелец поручил автономно продолжить работу после преждевременной остановки. Продолжили три прежних агента GPT-6.1 Sol и основной агент; браузер, платный API и общий бюджет контролировал основной агент. Цель — исправить наблюдаемые ошибки знакомства, понимания и интерфейса, затем проверить весь путь. Коммитов и публикации не было.

## Что изменилось для пользователя

- **Знакомая игра не заставляет начинать подбор заново.** Ранее добавленная замена нескольких карточек проверена настоящим picker; остальные игры и их отзывы сохраняются. «Оставить — хочу вернуться», отмена замены и явный флажок будущего исключения разделяют возвращение, знакомство и запрет. Новая логика также сохраняет прямое «хочу перепройти Skyrim», даже если рядом сказано «уже прошёл»; обычный пример похожей игры такого разрешения не даёт.
- **Короткие названия и части серии проверяются по источнику.** Skyrim/Скайрим, RDR2, BG3, «Ведьмак 3» разрешаются в настоящем каталоге. RDR2 больше не подмешивает RDR1, Portal 2 — Portal. Неоднозначное название не выбирается по популярности; модель получает разрешённые ID с цитатами, без приписанного отношения к игре.
- **Введённый ответ сохраняет смысл.** «Неважно» отправляется без прежнего скрытого текста, который можно вернуть отдельной кнопкой. Ранний переход к пониманию не игнорирует написанное. Черновики переживают reload, изменение условий и Back; повтор той же темы после поправки получает новый экземпляр. Ctrl+Enter работает в той форме, где находится курсор. «Назад» после сетевого сбоя и явного повтора восстанавливает слова поправки.
- **Время на сегодня проходит через весь подбор.** Только проверенная дословная цитата действующей реплики создаёт бюджет сессии. Часы полного прохождения, диапазон, неизвестность и условная доступность не становятся точным бюджетом. Время можно снять бесплатно; старый бюджет не возвращается из прежней реплики. Карточки честно предупреждают, если удобство прерывания не проверено.
- **Ошибку можно восстановить без повторного ввода.** После reload сохраняются сообщение и допустимость явного повтора принятого ответа. Бюджетный отказ не получает кнопку Retry. При неудаче интерпретации поправки прежние цели и карточки не продолжают показываться как актуальные.
- **Интерфейс стал проще проходить.** На первом экране свои слова видны раньше сетки направлений. «Моё» открывает знакомые игры, история вечеров подписана отдельно. Удаление вывода имеет одну бесплатную отмену, работающую после reload. Ключевые мобильные действия доступны без поиска внизу страницы.

Для трёх реально предложенных кооперативов добавлены проверенные численные сведения в существующий `data/verified-game-context.json`: Grounded 1–4, Valheim 1–10, Enshrouded 1–16. [Первичные источники и границы](../research-vault/overnight-2026-11/capacity-sources.md), [независимая проверка](../research-vault/overnight-2026-11/capacity-review.md). Основные каталоги не перегенерировались; их состав и ранжирование не менялись. Неизвестные значения других игр остаются неизвестными.

## Границы результата и следующая проверка

Живые сценарии синтетические; они не доказывают, что человек выберет или запустит предложенные игры. Ветка неизвестного желания проверена до следующего содержательного вопроса, без финального picker. Проверка числа игроков не подтверждает качество соединения, совместимость магазинов или длительность удобного сеанса.

Старые сохранённые карточки сохраняют прежние массивы оговорок; три новых факта применяются при следующем подборе/замене после перезапуска, исторические live-отчёты не переписываются.
