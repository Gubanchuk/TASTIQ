## Новое решение владельца, 31.10.2026

«АИ вместо клода будет теперь ОпенАи». Восстановление Anthropic больше не следующий шаг. Варианты для обсуждения: (1) минимальная замена финального AI-подбора поверх текущего движка; (2) OpenAI также уточняет смысл ответа и выбирает следующий полезный вопрос, а код проверяет ограничения; (3) полностью свободный AI-чат. Путь человека: домен → платформа у игр → время у кино/сериалов → компания → знакомые тайтлы с четырьмя реакциями → «за что» максимум про два → «что не так» максимум про один → жёсткие стопы → до трёх уточнений → результат. У игр отдельного экрана времени нет: длину спрашивает уточнение. Старые описания с обязательными жанрами, отдельным экраном настроения и playback до результата больше не описывают текущий путь.

Пять сит: можно ли → уже знакомо ли → достаточно ли качество → жёсткие личные запреты → подходит ли под обязательные условия сегодня. Неизвестная длительность обычно пропускается, поэтому отсутствие данных оставляет реальные промахи.

Вкус пересобирается из ответов на каждом запросе. Любовь к произведению не означает любовь ко всем его свойствам. Причина «обожаю» весит 1, подтверждённая причина «нравится» 0.7; слабый вывод признаков ограничен. Жалоба не штрафует весь каталог, если та же черта явно есть у любимого; явное «никогда» остаётся запретом. Настроение вечера хранится отдельно от постоянного вкуса. Уверенность вычисляет код; объяснение должно ссылаться на имеющийся факт.

Уточнения: до трёх, по 60 лидерам, `BELIEF = {K: 60, tau: 0.1, pStop: 0.5}`, `ASK.M = 5`, `gMin = 0.02`. Готовые пары про сегодня — настроение; общие пары «что важнее» — предпочтение вкуса. Не все задуманные в раннем плане типы вопросов были построены; текущее поведение смотреть в коде, а не в начальном проектном описании.

AI подключён 28.10 поверх движка: по умолчанию 40 кандидатов, с пожеланием 60; четыре результата, максимум два собственных предложения модели через поиск в уже отсеянном каталоге. В коде задано `claude-opus-5-5`, effort `low`; это конфигурация проекта, не проверка доступности модели на сегодня. Произвольный выдуманный тайтл или тайтл за жёстким ситом не проходит. Фразы модели отмечены её мнением. При ошибке остаётся подбор движка. Кеш одинакового состояния на час и объединение незавершённых одинаковых запросов снижают повторные расходы. Серверный таймаут 45 секунд, клиент перестаёт ждать примерно через 15.

Библиотека «Моё» и состояние — localStorage (`tastiq.site.library`, `tastiq.site` и история). Сохранённые причины переиспользуются в новом подборе, «Не знаю» не сохраняется; перенос между понравившимся и не понравившимся сбрасывает причину. Нет полноценной серверной учётной записи и синхронизации библиотеки. Возможность править причины прямо в «Моё» оставалась в ROADMAP.

При подготовке публичной/платной версии заново проверять актуальные условия, а не считать исследование октября юридическим заключением.

## Незаконченные решения и сырые места

Владелец ещё не утвердил в изученной истории:

1. Исторически — восстановление Anthropic через проверку организации или замену ключа. Решением 31.10 этот пункт заменён переносом AI-интеграции на OpenAI; модель и бюджет ещё предстоит выбрать.
2. Одинаковую первую страницу из восьми хитов для одинаковой ситуации.
3. Чтение «Уже смотрел» без оценки как слабого «нормально».
4. Дополнительную страницу при одной знакомой отметке: выигрыш в информации ценой лишнего экрана.
5. Включение `AI_SPARES=4` и увеличение стоимости. Историческая оценка одного платного сравнения была около $0.6; это не текущая котировка и не разрешённый бюджет.
6. Изменения вопроса о настроении: сильный штраф ухудшал персоны, хотя помогал синтетическому стенду. Архитектор предлагал узкие правила допуска вопроса и объединение одинаковых предупреждений вместо усиления всей формулы.
7. Доразметку фильмов 2019+: свежие фильмы проигрывают старым по полноте признаков. Точный текущий объём нужно пересчитать; в старых документах разные срезы, от 1 294 до примерно 1 500.

Последние наблюдения Claude, которые не были заново проверены глазами 31 октября:

- «Стена хитов» после удаления просмотренного уменьшилась, но осталась.
- При одной отметке и без AI выдача слаба: любителю «Друзей» предлагалось BB Ki Vines.
- Rainbow Six Siege, Garry's Mod, Left 4 Dead 2 имеют тег одиночной игры, который плохо описывает ожидаемый опыт на странице «один».
- Числа игроков в коопе нет: человеку с компанией предлагалась Enter the Gungeon на двоих.
- У «Теда Лассо» мало подходящих признаков, нет «ансамбля/дружбы»; просмотренные ситкомы оттесняли его.
- Настроение действует слабее постоянного вкуса; «держит в напряжении» распространено гораздо шире «спокойное», поэтому иногда все четыре карточки противоречат выбранному настроению.
- 71 цитата оставалась без перевода из-за отказа API. Текущий остаток не пересчитывался.
- На телефоне значок ошибки AI стоял отдельной строкой. Сайт исторически проверяли в Chrome; поддержка других браузеров не доказана.
- В журнале за 29 октября было 122 строки браузерных проверок. Это не реальные пользователи. Новые проверки также отделять от продуктовой аналитики.

## Как продолжать без повторения старой работы

Это порядок восстановления следующей сессии, а не начатая разработка:

1. Проверить Git и изменения после этого снимка. Прочитать последние разделы SUMMARY, не начинать заново шаги 0–10: они уже исполнены, хотя не все первоначальные идеи вошли в реализацию.
2. Если нужно оценить текущий UX, пройти игры и экранные домены на desktop и 390 px с отключённым или подменённым AI. Сначала назвать конкретные оставшиеся промахи.
3. Уточнить только решения, от которых реально зависит следующая работа. Рутинный выбор исполнения делать самостоятельно; владелец уже просил не задавать неопределённое «какие варианты ты хочешь».
4. Для изменений подбора сравнивать с отчётом 31.10: те же 12 прогонов и каталоги. Менять один фактор за раз. Правка страницы меняет, что узнаёт персона, её ответы и дальнейшие вопросы — простое изменение метрики не изолирует качество формулы.
5. Для исправлений данных проверять источник, цитаты и выбранные кейсы, затем тесты и персоны. Не «лечить» нехватку данных произвольной перенастройкой всех весов.
6. Платный замер AI — только при нужной проверке модели/промпта и определённом бюджете; офлайн-тесты с подменой проверяют интеграцию, но не качество настоящей модели.

`simulate.js` и `ask-stand.js` строят истину из признаков каталога; это проверка логики, не независимая проверка тегов. `src/stand/pools.json` закрепляет набор вкусов: его пересоздание ломает сравнимость. У `ask-stand.js` по умолчанию страницы по покрытию, а для близости к сайту нужен `--pages site`; доступны `--games`, `--screen`, `--truth`. Персоны и слепая оценка тоже не заменяют живых людей.

## Команды и эксплуатация

```powershell
npm test
npm run personas -- --tag <метка>

# Бесплатный просмотр без настоящего AI-запроса; переменные только для этого процесса shell.
$env:AI_ACCESS = 'off'
node --max-old-space-size=8192 src/server/server.js
# По умолчанию http://localhost:5173/ и /pick/.
# По окончании снять временную переменную, если shell будет использоваться дальше:
Remove-Item Env:AI_ACCESS
```

Сервер занимает много памяти из-за каталогов; выделять до 8 GB как в штатном `npm start`. После изменений ядра, серверной логики, каталогов и переводов — перезапуск. Для статических файлов — перезагрузка. Не считать историческое «сервер запущен» доказательством текущего процесса.

`npm run journal` читает `data/journal.ndjson`. `personas-ai.js`, `08-translate-quotes.js`, `npm run tag:api` и реальный `/api/ai/pick` — платные пути. Ключ хранится в `.env`, не читать его в вывод и не копировать в память. Браузерные тесты могут автоматически вызвать AI при восстановлении результата из localStorage; отключать на сервере или перехватывать до загрузки страницы. При проверках по возможности подменять `/api/log`, чтобы не пополнять пользовательский журнал тестовыми событиями.
