# Второй отзыв: копирование, продолжение и неоднозначные примеры

03.11.2026 владелец одобрил предложенный следующий шаг после обсуждения трёх скриншотов другого тестировщика. Исходный запрос про мультфильмы не сохранился; точную причину того промаха восстановить нельзя.

Изменено:

- В игровых и media-карточках название стало кнопкой с иконкой копирования. В буфер попадают отображаемое название и год, без лишних оценок и описаний. Рядом появляется «Скопировано». Если Clipboard API отсутствует или отклоняет запрос, показывается доступное readonly-поле с выделенным текстом. Enter работает, доступное имя заголовка остаётся названием произведения. Сохранение и отзывы не меняются.
- «Показать ещё» продублировано у заголовка выдачи для game/film/series/cartoon с пояснением «Ещё варианты с тем же запросом». Нижнее действие сохранено. Используется прежняя обработка more, ожидание, undo и исключение уже показанного; новые карточки не записываются как отрицательный вкус.
- В media planner найдено безусловное указание требовать точное произведение при неоднозначности. Теперь версия уточняется, когда от неё зависит дальнейшее решение: пересмотр, точное исключение или неописанное свойство. Для примера атмосферы используются только явно названные человеком свойства; можно не помнить версию. titleId остаётся null до разрешения неоднозначности, метаданные и свойства не угадываются.
- Независимое серверное сообщение о неоднозначности стало информативным: «Точная версия … не определена», вместо безусловного «Уточни название …». Человек может перейти к проверке понимания с достаточно описанным желанием.

- Две регрессии сначала упали: настоящий request содержал безусловную инструкцию, а сервис добавлял «Уточни название» даже при явном «версию не помню, она не важна». После исправления обе проходят. Остальные проверки identity/evidence/пересмотра сохранены.
- Native IAB, настоящий UI и каталоги, отдельный loopback-стенд с отключённой внешней сетью, подменённые ответы модели. Фильм на desktop; игра и сериал390px; мультфильм320px. Это проверка механики, не качества рекомендаций.
