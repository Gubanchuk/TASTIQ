# Пополнение каталогов от новых релизов к старым

Цель прогона — добавить от 10 000 уникальных выпущенных работ с изображениями в каждый из четырёх названных разделов. Считать прирост от `c59841b`, отдельно от размера каталога и числа работ, доступных в обычном подборе. Западные работы в аниме-стиле проходят прежнюю редакционную проверку.

- [x] Фильмы. Отобраны 10 000 по дате публичного релиза, сверены идентификаторы и оригинальные постеры.
- [x] Сериалы. Собран индекс TVmaze, сверены IMDb ID, формат, премьера и изображение. Подготовлены 10 000 работ по убыванию даты премьеры.
- [x] Игры. Сверены релиз, Steam AppID, тип приложения, издания и обложка для 10 000 работ.
- [ ] Аниме. Сверить перекрёстные ID, формат, происхождение и дату. Добавить запись в экранный снимок и реестр аниме с подтверждённым источником.
- [x] Для принятых партий сверены прирост, старые карточки, изображения, поиск, допуск к подбору и сборка. Партии оформлены отдельными коммитами для `origin/main`.

Границы импорта и правила проверки — в [очереди C0–C5](../../CATALOG_ROADMAP_2026-11-18.md). Правки пользовательской библиотеки и другие локальные изменения вне этого прогона. Используются существующие бесплатные источники и тесты с подменой платной модели.

Для новых фильмов без голосов не показывается зрительская оценка. У игр наиболее частая причина отсева — меньше 300 отзывов Steam.
