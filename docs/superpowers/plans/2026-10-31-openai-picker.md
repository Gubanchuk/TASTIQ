# Перенос подбора на OpenAI и диагностика промахов

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Перенести существующий финальный AI-подбор на OpenAI и показать, на каком этапе теряются цели персон.

**Architecture:** Сохранить диалог, сита, ранжирование, короткий список и проверку выбранных тайтлов. Заменить транспорт Anthropic на OpenAI Responses через штатный fetch Node; выделить общий конфиг, учёт токенов и диагностический отчёт. Новые зависимости не нужны; Anthropic SDK пока нужен историческим пакетным сборщикам.

**Tech Stack:** Node >=22, ESM, node:test, fetch, Responses API с JSON Schema.

**Spec:** Согласованный в чате ближайший этап, `docs/CODEX_CONTEXT.md`, раздел «Новое решение владельца». Пользователь ответил «поехали»; повторное согласование того же объёма не требуется.

## Global Constraints

- Никаких коммитов, публикации, удаления архивов и изменения существующего индекса Git.
- Каталоги, разметка, вопросы и формула подбора сохраняются.
- Рабочая модель: `gpt-6.1-sol`, effort `low`, переопределение через `OPENAI_MODEL` и `AI_EFFORT`. Это выбор исполнения, не результат сравнения качества.
- `OPENAI_API_KEY` только на сервере. `.env` не выводить. Настройки process.env имеют приоритет.
- Лимиты 30/час, 500/день, кеш и объединение незавершённых запросов сохраняются.
- Четыре основных выбора, 40 кандидатов (60 с пожеланием), максимум два собственных предложения, запасные по умолчанию 0.
- Платных проверок без заданного владельцем режима не запускать. Отсутствие ключа не мешает офлайн-работе.

## Review Focus

1. Ответ Responses содержит reasoning до сообщения: текст не обязательно в output[0].
2. Отказ, незавершённый/повреждённый ответ и сетевые ошибки сохраняют выдачу движка; токены не теряются при ошибке разбора.
3. Старый Anthropic-ключ не включает OpenAI; отсутствие нового ключа не порождает HTTP-вызов.
4. Цена считается по OpenAI input/output/cached tokens; для неизвестной модели не придумывается.
5. Диагностика использует состояние первого результата, а не состояние после нажатий «Уже смотрел»; отсутствие цели в коротком списке не запрещает собственное предложение AI.

## Журнал исполнения

- Начало: репозиторий без HEAD, коммиты и worktree не создаются. Реализация в текущей папке; исходники меняемых файлов сохраняются во временный каталог для сравнения на ревью.
- Решение: перенос только онлайн-подбора и его стенда. Пакетные сборщики разметки/перевода сохраняются как старые инструменты и явно помечаются в документации; без новых затрат и переразметки.
- Источники API: [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [Text generation](https://developers.openai.com/api/docs/guides/text), [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol). Проверено 31.10.2026. Стандартные ставки Sol: input $2, cached input $0.10, output $10 за миллион токенов; расчётная стоимость не равна счёту провайдера.
