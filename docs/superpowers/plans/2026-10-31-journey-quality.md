# Прохождение TASTIQ и проверка попаданий

> Исполнение: executing-plans, inline, один свежий финальный review. Пользователь просит исправить остановку на знакомых играх, самостоятельно прокликать весь путь, заранее задать по 2–5 ожидаемых игр. Коммиты/публикация не запрошены; текущий checkout и индекс сохраняем.

**Цель:** человек с чистого профиля понимает, что нажимать, проходит до рекомендации; три заранее описанных игровых сценария проверяются против нескольких допустимых целей без подгонки результата.

**Архитектура:** существующий Node/ES modules/vanilla UI. Минимальные исправления навигации и подсказок. Все ответы сценариев вводятся через интерфейс, без установки финального state. Для живого OpenAI подключается опциональный серверный transport с общим PaidBudget; offline-проверки сохраняют AI_ACCESS=off и отдельный journal. Результаты, входы и расходы сохраняются отдельно от прежних измерений.

**Spec / критерии:**
- Знакомые игры: понятная инструкция, счётчик, видимый переход внутри экрана плюс постоянная нижняя панель, отсутствие зависимости от обязательной оценки всех карточек. Пустой выбор явно разрешён.
- Пройти реальные клики: первая страница, выбор/снятие реакции, поиск/выбор найденного, другие игры, следующий шаг, назад/перезагрузка, пропуск, причины/ограничения/уточнения, карточки результата/исправление/«Моё». Desktop, средняя ширина и mobile; проверять реальную доступность кнопки до автопрокрутки locator.
- Заранее зафиксировать 3 сценария: история без сложных боёв; совместное приключение для двоих; динамичные повторные забеги. По 4 ожидаемых игры, без этих названий в пожелании/известных играх. Не менять набор после выдачи. Названия вне набора могут тоже подходить; fixed hits не равны удовлетворённости человека.
- Сохранить финальные состояния, полученные кликами, ответы UI и происхождение карточек. Отдельно: выход к результату, target hit@4, target eligibility/почему отсеяно, известные ошибки ограничений, субъективный разбор соответствия. Human labels остаются пустыми.
- Начать с бесплатного UX. Живой API: до 3 intent + 3 hybrid picks; при полезности сравнения до 3 direct picks на тех же входах. Предохранитель новой партии $0.75 с учётом резерва каждого запроса, общий потолок $5, существующий cumulative upper $1.0515197 /123. Продолжать eval/quality-round-2/budget.json; никаких старых runner или автоматических повторов uncertain.
- Обнаруженные пробелы каталога проверять точечно. Короткая анимация — отдельный изолированный опыт, не препятствует исправлению игрового пути. Production-каталоги и спорные фильтры без доказательства не менять.

## Review focus

1. Прокрутка, малое окно/zoom и длинный список: переход доступен и не закрывает реакцию.
2. Пустые ответы, поиск без результатов, back/reload: ни тупика, ни потери сделанных отметок.
3. Повторные клики/дубли Continue: ответ применяется один раз; границы ожидания модели честные.
4. Budget reserve до сети, concurrent calls/cache/errors/restart: один общий предел и отсутствие двойной оплаты или ложного нуля.
5. Targets frozen, actual clicked state, non-target suitable outputs: нет подгонки и смешения тестового/пользовательского журнала.
