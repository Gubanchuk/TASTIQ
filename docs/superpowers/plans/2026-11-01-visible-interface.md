# Видимая доработка /pick/game/

Основание: владелец не увидел заявленной работы по Impeccable/UI. Предыдущий цикл преимущественно исправил поведение; это не равнозначно оформленному интерфейсу. Текущий живой экран результатов зафиксирован в research-vault/interface-redesign-2026-11/before-desktop.png. Платные генерации для этой задачи не нужны.

Сохраняется одобренный нейтральный визуальный язык: системная типографика, синие действия/выбор, постеры как источник цвета, спокойные плоскости, один вопрос за раз. Техническое решение — текущий vanilla JS/Node, без библиотек или смены движка. Выбор композиции делегирован владельцем ранее; дополнительных согласований и статичных раскадровок не требуется.

## Конкретное изменение

1. Результат становится экраном сравнения игр: полноценная ведущая карточка с большим постером, заметным названием, читаемой причиной и оговоркой. Три альтернативы собраны рядом на широком экране, в один столбец на телефоне; причины видны без раскрытия. Пустое место и повторяющиеся служебные строки не задают иерархию.
2. Отмеченная для замены игра сохраняет визуальную идентичность, обложку и видимый статус. Отмена и возвращение относятся к этой карточке; общее подтверждение замены находится в панели действий. Отметка не превращается в исчезнувший безымянный блок.
3. Один визуальный ряд основных действий на карточке: выбор на сегодня и знакомство. Отзыв остаётся вторичным раскрытием. Кнопки выбора/замены различаются по весу; внешняя ссылка не конкурирует с ними.
4. Вопросы получают ясную композицию с полем собственных слов и компактными направлениями. Ранние экраны не делят пространство пополам с пустой сводкой. Навигация показывает реальные этапы, без выдуманного количества адаптивных вопросов.
5. Сводка, настройки и редкие действия образуют отдельную спокойную область. На промежуточной ширине она переходит ниже основного дела. Фокус поправки и «Моё» должны по-прежнему открывать доступные элементы.

## Последовательность

- Два изолированных Impeccable assessments: дизайн до просмотра detector и технические доказательства отдельно. Основной агент фиксирует живой Chrome; состояние владельца не используется для синтетических кликов.
- Одна реализация в файлах /pick/game/; логика controller, budget, данных и общего feedback-store не меняется.
- Один совместный просмотр desktop/mobile/question/review/result/marked/error с бесплатной подменой модели; затем один пакет существенных исправлений и подтверждение. Дополнительной декоративной полировки нет.
- Существующий полный набор тестов, синтаксис изменённых модулей, подтверждение действий в браузере. Не добавлять зеркальные тесты CSS.
