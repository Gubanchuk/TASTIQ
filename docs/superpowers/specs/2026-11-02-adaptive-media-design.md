# Адаптивный разговор для фильмов, сериалов и мультфильмов

Авторизация: владелец после объяснения различий и следующего плана сказал «давай все делай, что бы было заебись». Выполняем перенос на все три screen-domain. Ранее подтверждённый Conversation сохраняется, верх главной не меняется. Дополнительный выбор/одобрение не нужен. Технический выбор исполнителя: существующие vanilla JS/Node/Responses, отдельные media adapters поверх действующих catalog/recommend/feedback; без framework и без изменения каталогов/ранжирования.

Путь: желание своими словами (необязательные направления) → полезные вопросы по уже полученным ответам → проверяемое понимание с явными исправлениями/снятием фактов → несколько реальных вариантов → save/choose/seen/replace/keep/undo. По одному вопросу, no forced anchor quiz, unknown/indifferent/none не превращаются в отрицательное предпочтение. Можно рано перейти к пониманию. Back/reload сохраняют черновик и не вызывают платную модель. Correction supersedes old source; снятое предположение не восстанавливается.

Общие media-условия: доступное сегодня время отличается от общей длины сериала; компания, возраст ребёнка только если действительно смотрят с детьми, готовность к короткой/длинной истории/одному эпизоду. В мультфильмах нельзя автоматически предполагать детского зрителя. Сериальный статус/возрастная пригодность/длительность без данных не объявляются подтверждёнными. Действующие filters/policies остаются; unknown показывается оговоркой. Для фильмов лимит времени — runtime; для сериала — эпизод, а не суммарный хронометраж. Не утверждать, что количество сезонов известно, если каталог этого не подтверждает.

Каждый domain имеет отдельный state/storage/history, API строго отвергает domain/state mismatch. Старые game snapshots/keys/контроллер и library v1 не мигрируют молча. Прежний /pick/ сохраняется для явного продолжения старого маршрута; новые входы и навигация ведут /pick/watch/?domain=film|series|cartoon. Новый /pick/?start=<media> перенаправляется туда до legacy bootstrap. Старые сохранённые результаты остаются доступными явной ссылкой, без AI-call при чтении. /pick/#my продолжает вести в библиотеку.

Familiarity только конкретного произведения; viewed/started/dropped не равно dislike или постоянному запрету. Явный replay/return допускается. Замена меняет только помеченные карточки, сохраняет прочие отзывы/выбор/черновики; ошибка оставляет прежнюю выдачу и отметки. Save/choose используют настоящий library-store с media domain; lane не равен вкусу. Отдельная media-history хранит знакомство/явные исключения и не затрагивает game-history.

AI планирует вопрос и понимание одним Responses-call на содержательный ответ. Факты/время/context обязаны ссылаться на точный активный source/quote. Identity связывается локально по catalog aliases в собственном domain и собственном source; неоднозначность не разрешается популярностью, sequel не связывается с коротким parent. Прошлый вкус не становится сегодняшним желанием. Инъекции в ответах/каталоге — данные. Строгая schema, bounded input, cached/deduped POST, paid access/spend/receipts/journal с прежними guards.

Проверки: meaningful RED/GREEN core/AI/service/client/routes/history/replace; общий npm test и HTTP с модельной подменой; real browser 3media→results→save/library, correction/Back/reload/error/retry/replace на отдельных fixtures/journal, desktop/mobile в выбранном мире. Затем независимый code review и адресный UX review. Бюджет живой проверки: ≤$0.60, план до12 реальных model calls (3domain plan+pick, corrections/replacements при необходимости), после успешных бесплатных проверок и проверки живого ledger/lock. Не тратить cap автоматически и не считать synthetic responses humanfit. Main5177 перезапускается после backend changes; user state/tab сохраняется. Не коммитить/публиковать/удалять архивы.

Принятое исполнителем ограничение: действующие каталоги могут иметь пробелы по runtime/child suitability/series commitment; UI обязан показать неизвестность, а не дорисовать знания. Сохраняем текущие спорные продуктовые ограничения; не включаем anime/short/tvShort или новые запасные discovery автоматически.
