## Направление и границы

Авторские решения: цельная светлая оболочка с точным cobalt SVG, видимые «Подбор»/«Библиотека», компактный селектор домена; явный restart. Внутри — читаемый stepper, вопрос с вариантами и компактным пояснением, сводка в самостоятельной спокойной поверхности. Не копировать веера лендинга в формы. Редакторы пожелания/неясности открываются в центральной рабочей области, а в сводке остаются краткая проблема и действие. Нативные select получают доступную общую popover-оболочку с настоящим select в качестве состояния.

Результат: содержательное первое предложение и самостоятельные альтернативы; изображения contain, исходные proportions. У feedback оценка и собственное уточнение связаны с одной карточкой. Библиотека: один выбранный список, заметные counts, поиск и фильтры доступны, empty и no-results различны, reset, ограниченный вывод/«Показать ещё» для120+ сохранений. Названия во всех действиях конкретные.

Сохраняются: approved5B/uppercase02/Кобальт02, Golos/Unbounded; весь одобренный landing byte-identical; Conversation/AI/core/catalog/ranking/policy/квоты. Устойчивые drafts/reload/error/retry/back, correction checkpoint, familiarity/replace/undo, библиотечные данные/оценка/знакомство отдельно. Без новых зависимостей. Legacy не переоформлять. Никаких платных Responses. Не коммитить, не пушить, не публиковать эту новую переработку автоматически. Текущая ветка codex/workspace-usability-20261103, текущий checkout сохраняетlocalhost; чужую заметку deployment в CODEX_CONTEXT не откатывать.

## Проверка

Реальные контроллеры/каталоги на изолированном5180, AI_ACCESS=off + injected plan/pick, запрет внешнего fetch, отдельные QA storage/journal. Native CUA только: ни внешних Playwrightскриптов, ни evaluate-мутаций. Каждая видимая кнопка должна иметь запись в ACTION_MATRIX.md с исходом. Размеры1440/1280/1024/390/320, короткий экран; клавиатурный select и фокус;120+ библиотека; картинки load/fail; одна раскрытая обратная связь при сохранённых соседях. Тесты для поведения до фикса, затем full npm test/build; meaningful offline HTTP. Один mechanical detector после законченного build, fresh finish reviewer и documenter. Пользователь просит продолжать до завершения; ограниченный skill-проход косметики не ограничивает исправление подтверждённых функциональных дефектов/списка владельца. Продолжение по ledger, не перезапускать завершённые задачи после compaction.
