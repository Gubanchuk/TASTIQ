# Знакомые игры и удобство нового подбора

Владелец после свободного прохода: «он попал», но из трёх названных им вариантов два знакомы. Это один реальный отзыв о совпадении, не измерение общей пригодности. В браузере сохранён результат из четырёх карточек; не приписываем владельцу оценки каждой из них. Он поручил самостоятельно обдумать варианты, проверить путь и улучшить UI; вопросы и отдельное согласование этой локальной реализации не требуются.

Цель: знакомая игра не заводит человека обратно в анкету. На результате можно отметить несколько игр и заменить их вместе, сохранив цель, хорошие варианты и отзывы. Не заставлять заранее вспоминать всю библиотеку.

Рассмотрены: обязательная библиотека до старта (слишком тяжёлый вход), дополнительные примеры до результата (полезны для смысла, но не покрывают сыгранное), действия на карточках (основной путь), постепенная необязательная память знакомства (дополнение). Выбор реализации — Codex, не отдельное одобрение владельцем деталей.

## Поведение

- «Уже играл — заменить» отмечает карточку для общей замены. Отметка не вызывает модель. Можно отметить две подряд; основная кнопка становится «Заменить отмеченные (2)».
- «Оставить — хочу вернуться» и «Отменить» возвращают знакомую игру в сегодняшний выбор. Знакомство не равно прохождению, симпатии, антипатии или запрету серии.
- Отдельный явный выбор «Не предлагать в следующих подборах» сохраняет исключение в этом браузере. Без него действие касается текущего подбора. Список знакомых игр позволяет снять исключение или удалить ошибочную отметку. Старый профиль не импортируется.
- Явная замена использует прежние сводку, реплики, факты и условия. Меняются только отмеченные позиции; все оставленные ID и их отзывы сохраняются. Одна операция замены — максимум один picker, без повторного planner и автоматических платных повторов. Новые spares/discovery не включаются.
- «Вернуть предыдущие варианты» отменяет последнюю замену бесплатно. Предыдущая выдача и пометки сохраняются в snapshot; reload ничего платного не запускает.
- Ошибка или отсутствие кандидатов сохраняет выдачу/отметки и объясняет, что сделать дальше. При частичной замене честно видны незаменённые позиции, без вымышленных объяснений.
- Действия принимают только ID текущих карточек; результат повторно проходит действующие сита. Издания одной игры не возвращаются как замена; продолжение серии допустимо, если отдельно не запрещено.

## Интерфейс

Сохраняется нейтральный Native Utility: системный шрифт, существующие цвета, один вопрос на экран. Главный результат заметнее альтернатив; у каждой карточки видны выбор и знакомство. Полные оговорки и неподтверждённые условия доступны и не маскируются краткой причиной. Редактор запроса один; сводка по умолчанию компактна, подробные факты раскрываются. Одна точка перезапуска с восстановлением прежнего подбора. Ожидание/ошибка видны в панели текущего действия. Новый экран начинает чтение с заголовка; локальная отметка не прыгает вверх. Клавиатура сохраняет осмысленный фокус после изменений.

## Проверка

Подменённая модель и отдельный origin/журнал: две знакомые из нескольких, все знакомы, продолжение, постоянное исключение и его снятие, отмена до/после замены, reload, ошибка, истощение пула, сохранность отзывов и оставшейся карточки, издания и серия, клавиатура. Desktop1440×900, промежуточная ширина1024, mobile390×705 и446×705. Один общий просмотр после сборки и одна подтверждающая проверка после исправлений. Платные проверки не планируются. Тесты подтверждают поведение, не человеческое качество новой выдачи.
