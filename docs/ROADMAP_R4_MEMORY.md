# Память для подбора · 20 ноября 2026

В библиотеке появилась вкладка «Память». Здесь можно своими словами записать предпочтение для игр, фильмов, сериалов, мультфильмов или аниме. Условие можно оставить прямо в формулировке, например «В дороге люблю короткие выпуски». Запись можно исправить, отключить, включить снова или удалить.

| Источник | Как используется |
|---|---|
| Собственная запись | Попадает в новые онлайн-подборы выбранного раздела после нажатия «Сохранить». |
| Отзыв о прошлом подборе с разрешением на использование | Остаётся историей отдельного вечера. Его можно исключить из будущих запросов и разрешить снова. Если человек сохраняет на его основе отдельное предпочтение, в подбор идёт только актуальная формулировка. Удаление предпочтения оставляет исходный отзыв в истории. |
| Ответ о произведении из старой библиотеки | «Прежние ответы и отзывы» показывает собственные слова и ранее выбранные признаки. Человек решает, что из этого имеет смысл сохранить на будущее. |
| Закладка, оценка произведения, знакомство и исключение | Сохраняют свои прежние значения и отдельные действия. |

Хранилище браузера версии 1 разделяет записи по источникам. Для каждого изменения проверяется ревизия. Если в другой вкладке уже сохранили правку, форма сообщает о конфликте и сохраняет набранный текст. После удаления остаются идентификатор источника и ревизия, которые исключают его автоматический возврат из истории. При недоступном хранилище интерфейс сообщает об ошибке записи. [Реализация и проверки хранилища](../src/server/public/shared/taste-memory.js)

В запросы к онлайн-планировщику и подбору поступают актуальные включённые записи соответствующего раздела. В конкретном диалоге можно временно отключить отдельную запись. Приложение хранит первоначальную формулировку источника в браузере. Для модели формируется отдельный список с текущим текстом, разделом, ревизией и ссылкой на происхождение. Прошлая запись уступает сегодняшним словам человека. Офлайн-подбор по каталогу не интерпретирует произвольный текст предпочтения. [Проверки итоговых запросов модели](../test/taste-context.test.js)

При проверке нашли повторную отправку удалённого предпочтения через текст старого вопроса помощника. Теперь при смене памяти приложение обновляет данные для последующих запросов, сохраняя собственные ответы человека и исходный вид архива. Сценарий удаления после двух вопросов проверен для всех пяти разделов с перезагрузкой и подтверждением выдачи.

В Chromium на ширине 390 и 1366 px прошли создание и изменение записи, отключение с перезагрузкой, перенос старого ответа, исключение и восстановление отзыва. Из двух открытых форм удалось сохранить первую правку. На второй появилось сообщение о конфликте. Удаление связанной записи во время подбора уменьшило список перед подтверждением с трёх предпочтений до двух. Прежняя формулировка отзыва в запрос не вернулась. Платные вызовы отключены, использованы тестовые данные.
