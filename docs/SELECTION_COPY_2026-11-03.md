# Копирование текущего подбора —03.11.2026

По одобрению владельца реализован первый следующий шаг: «Скопировать подбор» в верхней панели результатов game/film/series/cartoon. Новый запрос к модели не нужен. Кнопка копирует обычный текст, не отправляет сообщение и не создаёт публичную ссылку.

В копию входят отправленные ответы этого диалога, текущее понимание, явно заданные условия/время, неясности и до четырёх именно показанных карточек в их порядке: название/год, видимые метаданные, причина с источником «мнение модели»/«данные каталога», оговорка, непроверенные условия и безопасная ссылка. Предварительный подбор явно помечен. Идентификаторы пользователя/диалога, библиотека, глобальное знакомство, оценки/заметки карточек, undo-выдача и неотправленные черновики не экспортируются.

Заменённые ответы пропускаются. Исходный текст затронутых удалением ответов не раскрывается повторно; для context/time учитывается и временной anchor удаления. Вместо него указывается, что часть ответов изменена; актуальные факты/условия остаются отдельной сводкой. Исходные ответы названы «Как уточнялся запрос», чтобы отличать их от итогового понимания.

Чистый formatter `shared/selection-copy.js` выбирает явные поля; в copy handler он вызывается в момент клика с текущими client.state/screen. Поэтому more/undo дают текущую выдачу. Общая функция copyText в title-copy.js сохраняет прежнее копирование отдельного названия. Успех — inline «Подбор скопирован»; отказ/отсутствие Clipboard API — readonly textarea, фокус, полное выделение и начало текста. Кнопка недоступна при обработке; clipboard не меняет состояние подбора, библиотеку и отзывы.
