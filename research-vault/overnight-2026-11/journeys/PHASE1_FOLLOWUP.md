# Первая фаза: продолжение проверки

01.11.2026. Дополнение после первоначальных двенадцати сценариев. Настоящий API, браузер и сервер не использовались.

## Исправление сохранности ещё не отправленного ответа

Воспроизведение: на вопросе об опыте игры набрать ответ, открыть условия и сменить компанию с трёх игроков на одиночную. Раньше reducer всегда переходил в review. Черновик оставался в localStorage, но исчезал из доступного маршрута; подтверждение подбора его не учитывало.

Добавлен интеграционный RED-тест `saving changed context keeps the visible unanswered question and its draft reachable without planning` в `test/overnight-journey-regressions.test.js`: реальный client → service → reducer, без DOM и API. До исправления экран становился `review`; после исправления активный talk-вопрос и его ID остаются на экране. Его draft доступен для явной отправки, старый факт из прежнего company-source удалён, контекст уже solo/partySize null. Сохранение условий вызывает planner 0 раз; следующий явно отправленный ответ вызывает подменённый planner 1 раз с точным текстом и новыми условиями. Из review/result редактирование условий по-прежнему ведёт в review. UI-исполнитель добавляет видимую подсказку, чтобы вопрос о прежней компании не выглядел новым подтверждённым пониманием.

Свежий адресный прогон после исправления:

`node --test test/overnight-journey-regressions.test.js test/conversation.test.js test/conversation-game-identity.test.js test/conversation-client.test.js`

**49/49**, отказов 0. Это счёт конкретного запуска, не окончательное число всей продолжающейся ночной работы.

## Независимая проверка идентификации названий

Просмотрены resolver, curated aliases, service binding/restore и тесты исполнителя history_trace. Подтверждены и переданы исполнителю следующие существенные ошибки:

1. В одной реплике с несколькими играми цитата `прошёл` не привязывалась к конкретному названию. Реплика `The Witcher 3 только начал; Kingdom Come прошёл`, факт ID Ведьмака/finished и цитата `прошёл` принимались. Исполнитель добавил отказ при нескольких source works и общей цитате без различимого названия. Новый отрицательный тест сначала RED, затем GREEN.
2. Бесплатное восстановление null-ID могло привязать игру по цитате, которой вообще не было в исходной реплике. Реплика `The Witcher 3 только начал`, сохранённая цитата `The Witcher 3 прошёл`, null-ID/finished привязывали ID Ведьмака. Для новых модельных предложений это ловил core; бесплатное исправление старого состояния обходило этот guard. Исполнитель добавил проверку точной непрерывной цитаты действующего источника перед binding/repair; новый тест GREEN. Неверная сохранённая цитата больше не создаёт ID/исключение.
3. Новый resolver отдаёт все распознанные игры, а старый planner input ограничивался двенадцатью. Проверено на корректной реплике длиной 421 символ с тринадцатью точными названиями: knownGames=13, API=0, ошибочное сообщение о превышенном размере/отсутствующем контексте. Общий лимит 240 KB далеко не достигнут. По согласованию с parent исполнитель повысил явную границу до 64 без усечения списка, сохранив лимит 240 KB и максимум 16 фактов. На 65-м названии возвращается конкретная бесплатная ошибка без повтора. Повторно просмотрены код и тест передачи 13 ID; свежий прогон identity+AI **20/20**, отказов 0. Найденная граница исправлена.

Другие проверенные свойства: длинный тайтл перекрывает вхождение короткого предшественника; Skyrim VR не смешивается с обычным изданием; неоднозначный alias не выбирается по популярности; null-ID repair требует уникального поддержанного тайтла одновременно в факте/цитате/источнике; знакомство само по себе не выводит симпатию или отрицательное впечатление.

Эта проверка независима для identity/service, но агент сам автор core-изменений и не объявляет собственное исправление независимым review. Окончательное общее ревью остаётся отдельным этапом родительского агента.

Открытых подтверждённых существенных замечаний по проверенному identity/binding-коду после трёх исправлений нет. Это не утверждение, что точная цитата сама по себе гарантирует верный смысл: отношение опыта к игре внутри сложной реплики всё равно требует адресной проверки настоящего planner.
