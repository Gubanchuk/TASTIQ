# Идентичность игр в разговоре — 01.11.2026

Обнаруженная в live/plan.json потеря Skyrim воспроизведена без API. В реальном каталоге 4 952 игры; прежний matcher name/ru/original не узнавал Skyrim, Скайрим, RDR2, BG3, Ведьмак3 и «Ведьмак 3». Он также добавлял первую Red Dead Redemption при упоминании второй и Portal при упоминании Portal 2. Срез до правок: before.json, исполняемая проверка diagnose-before.mjs.

## Изменение

- Новый `src/server/conversation-game-identity.js` индексирует name/ru/original и существующие catalog.aliases. Только целые токены, без edit distance, произвольных подстрок и выбора по популярности. Более длинное точное название владеет своим диапазоном текста, поэтому другая часть серии не добавляется из его префикса.
- Пять узких maintained правил в conversation-game-aliases.js включаются только при наличии точного canonical target в загруженном каталоге. Они покрывают короткие/русские формы Skyrim, BG3, RDR2, Witcher3 и Control; у каждого совпадения есть aliasId и каталоговый идентификатор основания. Общий поиск и каталог не менялись.
- Неоднозначный alias разных work не выбирает одну игру: ID остаётся неразрешённым, сводка просит уточнить название. Для защищённых общих слов вроде control/portal требуется явно игровой контекст или кавычки. Список защит консервативный и не является доказательством распознавания любой естественной фразы.
- knownGames получает только реально встретившиеся написания и точные sourceId/quote/aliasId действующих реплик. Superseded источники не участвуют. Planner transport сохраняет только эту identity metadata и прежние id/name/ru/year, не импортирует механику, exposure или оценку из каталога.
- После независимой проверки поднята устаревшая транспортная граница 12 → 64 разных распознанных work без усечения. Общий предел входа 240 000 UTF-8 байт и максимум 16 facts сохранены. Свыше 64 названий — конкретная бесплатная ошибка без dispatch и без предложения бессмысленного повтора. Это поддержка разумного контекста разговора, не обещание обработать целую библиотеку экспозиций.
- Предложенный nonnull gameId проверяется по work в собственной sourceId факта. Нельзя взять игру из другой реплики. Если цитата явно именует другую игру, ID отклоняется атомарно вместе с предложением. Если источник содержит несколько распознанных игр, общей цитаты «прошёл» недостаточно: цитата должна содержать соответствующее название.
- Null-ID чинится только когда текст конкретного факта именует ровно один разрешённый work, а точная цитата и активный исходный ответ поддерживают тот же work. Перед binding проверяется реальное непрерывное вхождение цитаты в действующий source; это защищает и бесплатный saved-state repair, который не проходит повторно через planner. Exposure/stance/quote не меняются. Общая цитата со Skyrim и RDR2 плюс отдельный факт «Skyrim пройден» достаточна; неизвестное название не заимствует единственную известную игру из той же реплики. Этот бесплатный repair работает также при восстановлении сохранённого нового v1 разговора перед confirm.

Согласованная соседняя интеграция: AI schema/instructions поддерживают gameIntent return/replay/reference/null; core-проекцию реализовал другой исполнитель. Только явное сегодняшнее return/replay разрешает вернуться к пройденной игре, условие не становится требованием; hard today exclude сильнее. Service также материализует показанный fallback-вопрос при бесплатном restore и сохраняет retryable:false из типизированных бюджетных ошибок. Модель/effort и платный transport не заменялись.
