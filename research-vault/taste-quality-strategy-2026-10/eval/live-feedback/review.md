# Финальный review: отзывы о вечере

31.10.2026. Один свежий reviewer GPT-6 Astra, read-only. Critical 0, Important 2, Minor 0. Замечания проверены исполнителем; один проход исправлений, без повторного reviewer.

1. **Пересекающиеся правки двух вкладок.** Обе могли записать разные payload с одним номером revision; ACK одной принимался другой. RED: `overlapping tab writes…` терял chosen. Исправление: основное хранилище IndexedDB с общей readwrite-транзакцией для чтения, правки и записи; сеть всегда вне транзакции. localStorage служит только кэшем/импортом прежних данных и уведомлением. ACK привязан к конкретному публичному содержимому. Web Locks над прежним кэшем оказались недостаточны в браузерном воспроизведении; этот промежуточный вариант заменён. Тестируются также устаревшие кэши и отказ постоянного хранилища; при отказе работает память окна с честной подписью. GREEN: unit и настоящий IndexedDB в двух вкладках, четыре серии одновременных правок, +8 ожидаемых ревизий, ни одного конфликта в отдельном финальном журнале.

2. **Исчезающий черновик.** RED в браузере: после ввода текста/причины нажатие fit оставляло оба поля пустыми. Исправление: черновик по run/card отдельно от сохранённого отзыва; восстанавливается при перерисовке, не передаётся серверу без submit. Если во время сохранения появился новый ввод, он не удаляется. GREEN: тест экранирования/отделения payload и браузерные fit, choice, storage-event, явная отправка. Фокус toggle-кнопок сохраняется по их новому состоянию.

Финальная проверка: `npm test` **195/195**, `npm run test:server` PASS с подменённым OpenAI; статические JS проходят `node --check`; браузер 1440×1000 и 390×844, AI_ACCESS=off. Повторены offline → reload → online и отсутствие горизонтальной прокрутки. Доказательства — `browser-check.json` (секция postReview), `browser-final-journal.ndjson`, скриншоты. Более ранняя browser-проверка в том же JSON описывает состояние до review; её ответы также синтетические.

Отложенное reviewer / решения исполнителя:

- Визуальная проверка: выполнена исполнителем в настоящем браузере; reviewer сам её не выполнял.
- Удовлетворённость людей: вне технической проверки, human labels не выдумываем.
- Подлинность клиентских оценок: прототип доверяет клиенту; текущие отзывы не объявляются удостоверенными людьми или репрезентативной статистикой.
- Будущие удаления ID/миграции каталога: live-каталог не менялся. До его будущего обновления отдельно проверить совместимость исторических снимков; invalid/outdated запись пока останется pending, не получит ложный ACK.
