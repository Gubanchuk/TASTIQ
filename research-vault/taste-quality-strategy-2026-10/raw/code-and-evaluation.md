# Проверенные наблюдения

Два независимых помощника GPT-6.1 Sol работали только чтением; API не вызывали. Root отдельно перепроверил состав targets Дани, итоговые агрегаты и текущие поля sessionOf, парсера, игровых признаков. Продуктовый код не менялся.

## Архитектура

Уже существуют adaptive questions, объяснение происхождения признаков, soft/hard запреты, локальные противоречия, raw text текущей сессии, «Моё», библиотека и исправления профиля. Предложение нового этапа расширяет их, а не объявляет отсутствующими.

Подтверждённые ограничения:
1. knownAnswer отбрасывает text сохранённого ответа при новом диалоге (dialogue.js:250). rememberAnswers не сохраняет answer для like с одним text без reasons/issues (app.js:232).
2. parseFreeText: `никогда не хочу хоррор, гринд иногда терпим` даёт hard=true обоим отрицательным признакам; `люблю сюжет, но только когда могу влиять на отношения` оставляет только story.central. Hard-маркер применяется ко всему тексту. Пользовательское подтверждение чипов уже существует.
3. Контраст «признак есть у любимого» переводит мягкую жалобу в local; сочетания и условия не представлены отдельным правилом.
4. nextQuestion смотрит top-60, требует покрытие признака среди лидеров; belief на основе score не является вероятностью удовлетворения.
5. note/wish не меняют поиск кандидатов; wish увеличивает список до 60 и входит в prompt. Два своих найденных моделью тайтла могут выйти за shortlist, но только среди прошедших сита.
6. Отсутствие required-тега не проходит сито; все части знакомой серии удаляются. Реальных ошибок этих правил среди прежних фиксированных целей не показано.
7. После seen/rating меняется профиль, но остальные AI-карточки сохраняются; AI не переосмысляет их заново автоматически.
8. Сумма независимых аспектов не выражает условие вроде «сложно нравится, если нет гринда». Модель получает raw text, но только после отбора этой формулой.

## Оценка

- 10/36: пересечение 48 итоговых карточек с тремя целями каждого из 12 состояний. 6 персон × 2 режима, не 36 людей.
- Games 0/12: четыре игровых состояния двух персон, не 12 игровых пользователей.
- Хотя бы одна цель: AI 7/12 состояний, движок 3/12. Также не принятие человеком.
- Tales from the Borderlands имеет в переданном входе подтверждённые персонажей/историю/выборы/юмор; R.E.P.O. страх/юмор/кооп/короткие сессии. Ноль targets не доказывает непригодность.
- Цели тоже имеют компромиссы: в данных Oxenfree/Night in the Woods отмечена тревожность; Hunt у Дани требует проверки состава команды. Не превращать targets в истину.
- Факт «за вечер 1–1.5 часа» и факт «кампания за пару вечеров» в стенде не эквивалентны. Полный today не отправляется модели.
- Расширение списка 19→27 целей показало рост охвата, не принятия. Больше данных и embeddings остаются гипотезами, не автоматическим лечением.

## Бесплатная проверка полей каталога

Прочитан `data/catalog.json`, только ключи и агрегаты. У объектов есть features, medianHoursAtReview, platforms, requiredAge, contentNotes. Не найдено отдельных верхнеуровневых полей с именами player/party/coop/session. Признаки session.short/session.long уже есть в словаре; это не точная длительность конкретного сеанса и не повод объявлять данные о сессиях полностью отсутствующими. Выборочные счётчики по предположенным именам не используются для оценки покрытия: имя признака надо сверять со словарём.
