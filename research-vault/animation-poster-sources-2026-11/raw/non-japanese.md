# Источники постеров для анимации за пределами Японии

## Сколько работ возвращает свежий индекс TVmaze?

### Вывод

В свежем индексе нашлось 155 связей с остатком очереди. Основной или альтернативный постер не подтвердился ни для одной из них. Проверка изображений эпизодов дала один кадр сериала *Fly-High and Huggy*.

### Подтверждённые данные

- Взяты 4 112 IMDb ID из `animation-alt-candidates.json` за вычетом 264 разных ID из поля `added` четырёх `run-screen-animation-alt-*.json`. Остались 3 848 записей. Среди них 843 фильма, 2 454 сериала и 551 мини-сериал. Причины исходной остановки — 3 615 без подтверждённой идентичности TMDB и 233 без постера. В остатке есть японская анимация, поэтому 3 848 служит размером общей очереди. [Очередь](../../../data/raw/c5-bulk/animation-alt-candidates.json), [протокол предыдущих партий](../../../docs/CATALOG_ROADMAP_2026-11-18.md)
- Октябрьский снимок содержал 90 604 записи до TVmaze ID 95 101. С момента локального снимка 20 октября 2026, 18:52 UTC в `/updates/shows` оказалось 3 714 поступивших или изменённых ID. Запрошены 380 страниц, содержащих эти ID или находящихся на верхней границе нового диапазона. 379 страниц вернули 90 309 записей. Одна верхняя страница вернула 404. Страницы TVmaze разбиваются по диапазонам числовых ID. [Справка TVmaze API](https://www.tvmaze.com/api#show-index), [локальный протокол](../../../data/raw/c5-bulk/deep-cartoon-tvmaze-work.json)
- В 155 связях обнаружены 94 совпадения по IMDb ID, 35 по названию и году, 26 по цепочке IMDb → Wikidata → TheTVDB ID → внешние ID TVmaze. Связям без собственного IMDb ID TVmaze дополнительно требовалось совпадение количества эпизодов. Итоговый отсев составили 49 записей японской анимации, 48 расхождений по дате, 20 по формату, 15 без основного постера, 12 с другим числом эпизодов, четыре без подтверждения происхождения, четыре с другим названием и три без числа эпизодов для проверки. [Документация внешних ID и изображений TVmaze](https://www.tvmaze.com/api#show-lookup), [локальный протокол](../../../data/raw/c5-bulk/deep-cartoon-tvmaze-work.json)
- Для 15 карточек без основного постера проверены полная карточка с эпизодами и список изображений. Четыре кандидата не подтвердили идентичность, один не подтвердил название, девять подтвердили работу, но не дали декодируемого постера или кадра. У британского *Fly-High and Huggy* (IMDb `tt31643950`, TVmaze 75252) совпали название, первый эфир 12 мая 2014 и пять последовательных эпизодов. Кадр первого эпизода *The Inflatorater* (TVmaze 2794193) загрузился по HTTPS и декодировался как 1920×1080. [Эпизоды IMDb](https://www.imdb.com/title/tt31643950/episodes/), [сериал TVmaze](https://www.tvmaze.com/shows/75252/fly-high-and-huggy), [кадр эпизода](https://www.tvmaze.com/episodes/2794193/fly-high-and-huggy-1x01-the-inflatorater)

### Выводы для работы

- Обновление индекса подходит для дешёвой периодической сверки свежих релизов. Исторический остаток дал один кадр на 3 005 серийных записей и ни одного постера по условиям этого прогона. Отдельная выборка изображений эпизодов имеет смысл только при допустимости кадров. [Условия API TVmaze CC BY-SA](https://www.tvmaze.com/api#licensing)

### Пробелы

- Не перепроверены все 48 конфликтов дат по первичным источникам. Некоторые разрывы велики и могут отражать разные версии, например *What-a-Mess* (IMDb 1979, TVmaze 1990). Доступная дата начала эфира по конкретной стране может относиться к повторному выпуску. [Локальный список](../../../data/raw/c5-bulk/deep-cartoon-tvmaze-work.json)
- Техническая доступность и условия TVmaze API подтверждены. Отдельное разрешение первоначального владельца прав на кадр *Fly-High and Huggy* не найдено. [Условия API](https://www.tvmaze.com/api#licensing)

## Сколько дают TheTVDB, OMDb и полные списки изображений TMDB?

### Вывод

Ссылки на TheTVDB полезны для установления идентичности и выхода на дистрибьютора. API TheTVDB и OMDb требуют доступа, которого в окружении проверки не было. Все 233 обращения к полным спискам изображений TMDB подтвердили отсутствие постеров у проверенной группы.

### Подтверждённые данные

- В сохранённых Wikidata claims для остатка обнаружены 216 разных IMDb ID со свойством P4835 и 41 со свойством P12196. Если оставить однозначную сущность Wikidata и убрать записи с явной страной Япония или японским языком в claims, получаются 231 уникальный IMDb ID и 233 записи двух свойств. Отсутствие отметки о японском происхождении не доказывает другое происхождение. [P4835](https://www.wikidata.org/wiki/Property:P4835), [P12196](https://www.wikidata.org/wiki/Property:P12196), [локальные claims](../../../data/raw/c5-bulk/animation-alt-wikidata-claims.ndjson)
- Выборочные открытые страницы TheTVDB подтверждают пользу идентификаторов и пределы проверки дат. *Pat a Mat znovu v akci* (IMDb `tt9574822`, TVDB Movie 146379) — чешский анимационный фильм с релизом 7 июня 2018. Точную дату, происхождение и оригинальный образ дали дистрибьютор Bioscop и Czech Film Center. Кандидат передан исследователю фильмов. У *Go Go Gophers* (IMDb `tt0062566`, TVDB Series 256453) поле First Aired показывает 1964 при 1966 в очереди. У *Rugrats: Pre-School Daze* (IMDb `tt3189040`, TVDB Series 267205) TheTVDB показывает эфир 2008 при 2005 в очереди. Перед переносом для таких карточек отдельно подтверждается версия или первый релиз. [Pat a Mat в TheTVDB](https://thetvdb.com/movies/pat-mat-znovu-v-akci), [Bioscop](https://www.bioscop.cz/filmy/pat-a-mat-znovu-v-akci), [Czech Film Center](https://www.filmcenter.gov.cz/en/films-people/3059-pat-mat-in-action-again), [Go Go Gophers](https://www.thetvdb.com/series/go-go-gophers), [Rugrats](https://thetvdb.com/series/rugrats-pre-school-daze)
- TheTVDB предоставляет v4 API с поиском по внешнему ID и отдельными маршрутами для изображений. Получение ключа и способ использования привязаны к проекту. Условия API прямо исключают право на показ изображений как часть лицензии и относят поиск прав к пользователю API. OMDb предлагает запрос по IMDb ID, а отдельный Poster API доступен уровням поддержки, перечисленным в документации. Проверка присутствия имён настроек в переменных окружения и проектном `.env` не обнаружила OMDb/TVDB credentials. Значения ключей и сторонние credentials не использовались. [TheTVDB Swagger](https://thetvdb.github.io/v4-api/), [условия TheTVDB](https://www.thetvdb.com/tos), [документация OMDb](https://www.omdbapi.com/)
- Для всех 233 записей с исходным `no-poster` повторный `/find/{imdb}` дал единственную запись ожидаемого формата. Запрос `/{movie|tv}/{id}/images` без ограничения языка, через настроенный проектом токен чтения, вернул пустой список `posters` для каждого из 233 результатов. Положительные контроли тем же маршрутом дали 167 постеров для *Shrek* (TMDB movie 808, 27 различных значений языка изображения) и 184 для *The Simpsons* (TMDB TV 456, 25 значений). [TMDB Find](https://developer.themoviedb.org/reference/find-by-id), [изображения фильма](https://developer.themoviedb.org/reference/movie-images), [изображения сериала](https://developer.themoviedb.org/reference/tv-series-images), [результаты 233 проверок](../../../data/raw/c5-bulk/deep-cartoon-tmdb-images-work.ndjson)

### Выводы для работы

- Использовать TVDB ID как мост к первичным страницам. В этом прогоне пример Bioscop дал оригинальный постер и точную дату. Саму галерею TheTVDB массово не обходили. [API и условия TheTVDB](https://thetvdb.com/api-information), [страница дистрибьютора Bioscop](https://www.bioscop.cz/filmy/pat-a-mat-znovu-v-akci)
- Языковая фильтрация TMDB не объясняет пропуск в 233 проверенных карточках. Выгрузки TMDB Daily ID Exports предназначены для идентификаторов, поэтому не заменяют проверку изображений. [Что содержат Daily ID Exports](https://developer.themoviedb.org/docs/daily-id-exports)

### Пробелы

- Покрытие всей очереди через авторизованные TVDB и OMDb API не измерено. Проверка обхода регистрации и временные ключи не применялись. [Условия TheTVDB](https://www.thetvdb.com/tos), [доступ OMDb](https://www.omdbapi.com/)

## Что дают открытые архивы и страницы создателей?

### Вывод

Связи Wikidata с изображениями и страницами издателей дали пять файлов с подтверждённой идентичностью и содержимым. Два файла имеют явное указание лицензии или статуса на Commons. Остальные три опубликованы производителем или дистрибьютором, но условия повторного показа не установлены.

### Подтверждённые данные

- В остатке не оказалось связей с P3383. У девяти IMDb ID встречается P18. Из них две связи указывают на пригодное изображение конкретной работы. *Peludópolis* (`tt0196839`, Q2091605) — аргентинский полнометражный фильм 1931 года. Commons маркирует исторический постер 900×1348 как PD-AR-Anonymous и просит указать источник. Секретариат культуры Аргентины показывает ту же афишу, отдельно проверено 345×517. Источники расходятся по точному дню релиза и длительности, поэтому в JSON записан год. [Wikidata](https://www.wikidata.org/wiki/Q2091605), [Commons и права](https://commons.wikimedia.org/wiki/File:Pelud%C3%B3polis_poster.jpg), [секретариат культуры](https://www.argentina.gob.ar/noticias/dia-nacional-de-la-animacion-argentina)
- *Delfy and His Friends* (`tt1292277`, Q2919683, Испания, 1992) — оригинальное изображение 1280×720 с заставки трейлера самого D'Ocon Films. Commons указывает CC BY 3.0 и автора D'Ocon Films. Каталог правительства Каталонии подтверждает название и производителя. Остальные P18-изображения представлены логотипами, фото создателей или другими иллюстрациями без подтверждения пригодности. [Wikidata](https://www.wikidata.org/wiki/Q2919683), [Commons и лицензия](https://commons.wikimedia.org/wiki/File:Delfy_Thumbnail.jpg), [каталог Catalan films & television](https://drac.cultura.gencat.cat/bitstream/handle/20.500.12368/37087/Catalan%20films%20%26%20television%201989-1990.pdf?isAllowed=y&sequence=1)
- Среди шести проверенных остаточных Netflix ID с однозначной связью Wikidata без явных признаков Японии пять вернули 404 и одна страница показала точный сериал. У *Canimals* (`tt2174349`) с официальной страницы Netflix с региональной датой 2012 получен кадр 1280×720. Первая премьера 2011 подтверждена каталогом KOCCA. Государственный каталог Catalan Films перечисляет Корею, Испанию и Великобританию. [Точная карточка Netflix](https://www.netflix.com/title/80063743), [каталог KOCCA](https://www.kocca.kr/crawling/upload2013/men/2015DirectoryBook.pdf), [Catalan Films](https://catalanfilms.cat/en/productions/canimals)
- Среди трёх выборочных официальных страниц производителей или дистрибьюторов две дали точное изображение. У французского *Floopaloo, Where Are You?* (`tt5116278`, Q3073355, 2011) каталог Xilam отдаёт подписанный горизонтальный арт 1920×1357, а год и первую поставку 10 эпизодов подтверждает годовой отчёт Xilam. У российского *Little Tiaras* (`tt9074470`, Q56308269, 2018) Madgic Distribution показывает 78 серий за 2018–2023 и тематическое изображение 960×490. Страница MNC Animation для *Kiko* в проверенной среде вернула HTTP 403, повторных попыток через другие способы доступа не было. [Xilam](https://xilam.com/en/media/floopaloo-where-are-you/), [отчёт Xilam за 2011](https://echanges.dila.gouv.fr/OPENDATA/AMF/BWR/8888/01/FCBWR079672_20120509.pdf), [Madgic Distribution](https://madgicdistribution.com/programs/little-tiaras/), [карточка Kiko](https://www.mncanimation.com/ip/kiko)
- У 71 IMDb ID остатка есть P856 (официальный сайт), у 16 есть P2397 (канал YouTube), у пяти P1651 (видео YouTube). Это верхние границы для ручной проверки, с пересечениями. У 57 есть EIDR ID P2704. Стандарт EIDR помогает связывать работу с альтернативными идентификаторами и не даёт лицензии на постер. [Свойства Wikidata](https://www.wikidata.org/wiki/Wikidata:WikiProject_Movies/Properties/identifiers), [EIDR о реестре](https://www.eidr.org/faq)
- Government of Canada публикует две машиночитаемые выгрузки National Film Board по онлайн-произведениям, одну в CSV и одну в MARC21. Оба официальных ZIP в среде проверки не разрешились по DNS, поэтому покрытие не посчитано. В сохранённых Wikidata claims для этой очереди нет прямых P4606. API Danish Film Institute требует отдельной HTTP-аутентификации. У iTunes Search API изображения для продвижения доступны с условиями о контексте использования и размещении ссылки на магазин. [NFB CSV](https://open.canada.ca/data/en/dataset/deeaddd4-fa52-4fd7-9668-d66940280493), [NFB MARC21](https://open.canada.ca/data/en/dataset/1a9e3222-d446-4d35-865a-ae3522e18c31), [Wikidata P4606](https://www.wikidata.org/wiki/Property:P4606), [DFI API](https://api.dfi.dk/documentation/dfiapi.pdf), [Apple Search API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/index.html)

### Выводы для работы

- Для ограниченной партии начинать с P18/P856 или внешнего ID, затем брать дату, страну и сам файл у студии, вещателя, дистрибьютора или архива. В подборке шесть кандидатов, включая кадр TVmaze, у каждого сохранены оригинальный URL, размер, источник и степень подтверждения прав. [JSON с доказательствами](../../../data/raw/c5-bulk/deep-cartoon-alternatives.json)

### Пробелы

- Для большинства из 3 848 ID не доказано наличие открытого массового источника одновременно с точным сопоставлением, архивным изображением и пригодными правами. Проверенный образец страниц издателей мал и не предназначен для экстраполяции. Лицензия на NFB метаданные отдельно не определяет прав на отдельные произведения. [Документ NFB о публикации открытых данных](https://publications.gc.ca/collections/collection_2017/onf-nfb/NF4-11-2016-eng.pdf)
