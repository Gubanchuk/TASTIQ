# Источники изображений для каталога анимации

Проверка 19 ноября 2026 года охватывает остаток очереди из 3 848 IMDb ID. Реестры ниже показывают происхождение изображения, основание для сопоставления и ограничения источника. Статусы и размеры выборок приведены в [журнале проверок](Research_Log.md).

Для TASTIQ взята афиша с сайта Telegael, студии-сопродюсера. ## Метаданные и связи между каталогами

| Источник | Как применяли и где остановились |
|---|---|
| Wikidata и TMDB | Свойства Wikidata дали прямые ID TMDB, ссылки `P856` на издателя и отдельные изображения `P18`. TMDB использовали для повторной проверки по ID, поиска по названию и году и запроса полного списка изображений. Совпадение внешнего ID проверяли по названию, году, формату и доступным признакам страны. [Свойства Wikidata](https://www.wikidata.org/wiki/Wikidata:WikiProject_Movies/Properties/identifiers), [P856](https://www.wikidata.org/wiki/Property:P856), [P18](https://www.wikidata.org/wiki/Property:P18), [TMDB Find](https://developer.themoviedb.org/reference/find-by-id), [изображения фильмов](https://developer.themoviedb.org/reference/movie-images), [изображения сериалов](https://developer.themoviedb.org/reference/tv-series-images) |
| Anime Offline Database, Fribb, Kometa, Otaku и animap | Закреплённые снимки соединяют IMDb с AniDB, MAL и AniList. У некоторых связей совпадает укрупнённый IMDb ID всего сериала или сборника. Кандидатов дополнительно проверяли по первичным записям. В релизе animap от 16 ноября 2026 таблица AniDB уже не содержит IMDb. [AOD 2026-27](https://github.com/manami-project/anime-offline-database/tree/2026-27), [Fribb](https://github.com/Fribb/anime-lists/blob/68ec5f2e7f69e6f00fd67c795a5e683d871a2ba6/anime-list-full.json), [Kometa](https://github.com/Kometa-Team/Anime-IDs#format), [Otaku](https://github.com/Goldenfreddy0703/Otaku-Mappings/blob/58f5e5799c3513fc047f308ce54c9c5435befed9/anime_mappings.db), [animap 17 октября](https://github.com/cplieger/animap/releases/tag/v2026.10.17), [animap 16 ноября](https://github.com/cplieger/animap/releases/tag/v2026.11.16) |
| TVmaze, TheTVDB и OMDb | TVmaze отдаёт индекс сериальных ID и изображения эпизодов. Открытая карточка TheTVDB помогла выйти на Bioscop и найти первичное свидетельство. Массовый доступ к API TheTVDB и OMDb не проверяли из-за отсутствия настроенных ключей. TheTVDB отдельно оговаривает права на изображения. [TVmaze](https://www.tvmaze.com/api#show-index), [карточка Pat a Mat в TheTVDB](https://thetvdb.com/movies/pat-mat-znovu-v-akci), [TheTVDB API](https://thetvdb.github.io/v4-api/), [условия TheTVDB](https://www.thetvdb.com/tos), [OMDb](https://www.omdbapi.com/) |
| Реестры и выгрузки с ограниченным охватом | EIDR помогает найти другие идентификаторы. Обе официальные выгрузки NFB не открылись из-за DNS в среде проверки. DFI требует HTTP-аутентификации, а Apple ограничивает использование промоизображений условиями контекста и размещения ссылки на магазин. [EIDR](https://www.eidr.org/faq), [NFB CSV](https://open.canada.ca/data/en/dataset/deeaddd4-fa52-4fd7-9668-d66940280493), [NFB MARC21](https://open.canada.ca/data/en/dataset/1a9e3222-d446-4d35-865a-ae3522e18c31), [DFI](https://api.dfi.dk/documentation/dfiapi.pdf), [Apple Search API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/index.html) |

Полные подборки с привязками к IMDb ID и адресами файлов доступны в [записях по каталогам аниме](raw/anime-crosswalk.md), [записях по анимации за пределами Японии](raw/non-japanese.md) и [записях по оригинальным афишам фильмов](raw/official-film-posters.md).
