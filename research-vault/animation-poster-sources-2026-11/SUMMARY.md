# Изображения из других каталогов анимации

## Вопросы

1. Сколько из 3 848 отложенных работ восстановлено и какие источники дали изображения?
2. Почему массовые источники не закрыли остальную очередь?
3. Что теперь можно проверить в TASTIQ и сколько кандидатов осталось?

## Коротко

- Добавлено 132 карточки, из них 21 аниме и 111 мультфильмов. У 126 есть оригинальные постеры, у пяти кадры, у одной промообложка.
- Архивы, студии, дистрибьюторы и каталоги аниме дали 50 работ. Альтернативные способы сопоставления с TMDB дали ещё 82.
- Поиск TMDB по названию и году не дал точного совпадения для 3 291 из 3 584 проверенных входов. Дополнительная проверка галерей для 233 записей не дала постеров.

## Критерии

Принимались оригинальные изображения конкретного произведения с декодируемым HTTPS-файлом и ссылкой на источник. Для допуска проверялись идентичность работы, формат, релиз и страна для японского аниме. Для повторного импорта учитывались уже принятые IMDb ID, сущности Wikidata и дубли изображений. Дополнительных учётных записей и платных запросов не понадобилось.

## Ответы

**1. Сколько восстановлено и откуда.** 132 карточки. Студии, архивы, дистрибьюторы и другие каталоги изображений дали 37, таблицы соответствий аниме ещё 13. По прямым ссылкам Wikidata на TMDB добавлены 22, по названию и году 60. Поиск по названию проверил больший набор и дал больше карточек, а прямая связь Wikidata дала больше добавлений на проверенный вход. У обоих методов найдены противоречия, поэтому совпадения сверялись по фактам о релизе. [Поиск TMDB](https://developer.themoviedb.org/reference/search-tv), [Wikidata](https://www.wikidata.org/wiki/Help:Data_access)

**2. Почему массовые источники не закрыли остаток.** У 3 291 из 3 584 входов не нашлось точного совпадения формата, названия и года в выдаче TMDB. В дополнительных галереях 233 точных записей не было ни одного постера. Обновлённый индекс TVmaze дал 155 связей, из них одна дала подтверждённый кадр после проверки эпизодов. Все 14 исходных IMDb ID, найденных через Kometa, уже входили в 15 совпадений Fribb. [Галереи TMDB](https://developer.themoviedb.org/reference/movie-images), [индекс TVmaze](https://www.tvmaze.com/api#show-index), [Fribb](https://github.com/Fribb/anime-lists), [Kometa](https://github.com/Kometa-Team/Anime-IDs)

**3. Что можно проверить и сколько осталось.** Локальный каталог содержит 66 654 карточки, из них 4 319 аниме и 7 899 мультфильмов. Реестр содержит ссылки на источники всех 132 изображений. У аниме без QID, подтверждённых издателем или архивом, карточка подбора ведёт на страницу первоисточника. Для 3 716 оставшихся кандидатов доступны результаты фильтров и источники. Среди них 3 495 из группы без точного результата TMDB и 221 из группы без постера. [Контекст каталога](../../docs/CODEX_CONTEXT.md)

Все 132 изображения загрузились в Chromium. Три карточки проверены в мобильной библиотеке после сохранения через API поиска и перезагрузки страницы. Сборка, HTTP-проверка и 719 тестов прошли. [Журнал проверок](Research_Log.md)
