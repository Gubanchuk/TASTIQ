# TASTIQ — Кобальт

Выбрано владельцем 03.11.2026: медведь5B, прописное написание02 и палитра02 «Кобальт».

Основной логотип целиком кобальтовый. На тёмном фоне используется светлая обратная версия. SVG содержит контуры знака и букв, шрифт устанавливать не требуется.

|Роль|Цвет|
|---|---|
|Основной|#3154D6|
|Текст|#1C2945|
|Светлый фон|#F1F4FC|
|Тёмный фон|#15213D|
|Логотип на тёмном фоне|#DFE8FF|
|Дополнительный|#ABC9ED|

В svg/: logo — связка, symbol — медведь, wordmark — надпись. cobalt/inverse — основные цветные версии, black/white — монохромные. logo-accent — дополнительная версия с цветным знаком и тёмной надписью. favicon.svg — отдельный знак для вкладки браузера.

В png/: прозрачные логотипы4560×1108, знак1024×1024, favicon16/32, apple-touch-icon180 и превью на двух фонах. PNG отрисованы из этих SVG нативным браузером.

Масштабировать с сохранением пропорций; внутренний просвет медведя остаётся прозрачным. Палитра и токены приложены отдельно, чтобы переносить их в интерфейс отдельным изменением. История поиска и генеративные эскизы в комплект не включены.
