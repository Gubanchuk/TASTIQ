# TASTIQ: 5B + 02

Владелец выбрал знак5B и прописное написание02. Эти SVG собраны из контуров выбранного эскиза lettering-study-v1.png; повторная генерация не выполнялась. Уменьшен масштаб знака относительно букв, выровнена его нижняя опора, скорректированы расстояние знак–слово и небольшие интервалы букв. Конкретные параметры сохранены в vector-build-report.json уровнем выше.

- tastiq-logo.svg / tastiq-logo-white.svg — горизонтальная связка.
- tastiq-symbol.svg / tastiq-symbol-white.svg — отдельный медведь.
- tastiq-wordmark.svg / tastiq-wordmark-white.svg — надпись отдельно.
- tastiq-logo.png — прозрачный PNG4560×1108, отрисован браузером из SVG.
- tastiq-preview.png — превью2600×874 на белом фоне, отрисовано из того же SVG.

Все SVG имеют прозрачный фон, содержат настоящие замкнутые Bézier-контуры и не встраивают PNG или шрифты. Белые SVG предназначены для тёмного фона. PNG — растровые экспорты: логотип прозрачный, превью намеренно с белым фоном. Они не заменяют масштабируемый SVG-мастер. Рабочий просмотр: http://127.0.0.1:5184/selected/ . Цветная палитра пока не выбрана; финальная собранная связка ещё ожидает реакции владельца.

Воспроизведение: read-selected-contours.ps1 читает исходный PNG для анализа; build-vector-02.mjs переводит выделенные контуры в SVG и собирает пропорции. Исходный PNG не изменяется. При публикации используется готовый SVG; вспомогательные скрипты не нужны в runtime.
