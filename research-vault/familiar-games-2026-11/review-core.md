# Адресная независимая проверка ядра и хранения

Дата: 01.11.2026. Проверены текущие `src/core/conversation.js`, `src/server/conversation-service.js`, `src/server/public/shared/game-history.js`, `src/server/public/shared/conversation-client.js` и связанные тесты по спецификации `docs/superpowers/specs/2026-11-01-familiar-games-design.md` и плану `docs/superpowers/plans/2026-11-01-familiar-games.md`.

## Подтверждённая существенная находка — исправлена

**Единственный допустимый кандидат не мог заменить знакомую игру.** До исправления сервис разрешал замену при одном оставшемся кандидате, но настоящий `aiPick` в `src/ai/pick.js:92` отвергал список короче двух. Тесты с подменённым picker эту границу не покрывали.

Бесплатное воспроизведение на `fixtureCatalog`: текущие карточки `1` и `3`, отмечена `1`, сохранённые исключения содержат все ID, кроме `1`, `3`, `4`. После исключения текущих карточек и их изданий допустим только `4`. До исправления результат сохранял `1`, выдавал «выбирать не из чего», обращений к API было 0.

Исполнитель исправил границу в `src/server/conversation-service.js:44`: при единственном допустимом кандидате сервис показывает проверенную карточку каталога без вызова picker, API или spend. У новой карточки нет `ai`; `replacementSource:'engine'`, пояснение сообщает об источнике. Нетронутая карточка сохраняется без изменений. Общий порог `aiPick` и прежние маршруты не менялись.

Повторная проверка текущей ветки и регрессионного теста `the sole admissible replacement is shown honestly from catalog without any picker dispatch or spend` подтвердила исправление. Открытых существенных замечаний по проверенному коду не осталось.

## Проверенные границы

- Замена сохраняет сводку, факты, реплики и нетронутые карточки; повторно применяет сита, исключает текущие и ранее скрытые игры вместе с изданиями. Серия сама по себе не блокируется.
- Возвращение к знакомой игре передаётся picker как явное решение на сегодня без оценки вкуса. Явное сегодняшнее жёсткое исключение остаётся сильнее.
- Замена и явный повтор не запускают planner. Ошибка сохраняет варианты и отметки; actionless restore и undo бесплатны. Exact duplicate requests используют общий выполняющийся запрос и успешный cache.
- Изменение запроса снимает устаревшие пометки/undo; старые v1 snapshots получают безопасные значения familiarity. Идентификаторы и replacement metadata ограничены и проверяются.
- `game-history.js` хранит знакомство отдельно от legacy-профиля. Только явный `blocked` создаёт будущие исключения; отсутствие оценки не выводит симпатию/антипатию. Отдельные ключи не перезаписывают чужие игры при последовательных правках вкладок.
- `conversation-client.js` сохраняет прежний подбор с черновиками для бесплатного восстановления после restart. Сетевой повтор использует тот же payload, включая снимок явных исключений. Reload сам не повторяет платное действие.

Результат: **51/51**, отказов 0. Отдельная проверка client/history перед финальным исправлением: **17/17**. Промежуточные отказы параллельно дописываемых тестов не трактовались как окончательные находки; в итоговом запуске они проходят.

Это адресная проверка кода и бесплатных тестов. UI, производственный сервер, живой пользовательский журнал и платный API в этой проверке не использовались. Человеческое качество подбора не оценивалось. Отдельная реализация переноса отзывов авторства этого же агента не объявляется независимо проверенной этим отчётом.
